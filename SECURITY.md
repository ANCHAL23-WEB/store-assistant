# Security Policy

## About this project

Store Assistant is a portfolio/demo project, not a production system handling
real user data. The product catalogue is synthetically generated, and there
are no real customer accounts, payments, or personal data involved.

## Known limitations

See the "Known Limitations" section in the README for current gaps (e.g.
CORS configuration, authentication) that would need to be addressed before
any production use.

## Reporting a vulnerability

If you find a security issue in this project, please open a GitHub issue
describing the problem. Since this is a demo project rather than a live
service handling sensitive data, there's no formal disclosure process or
bug bounty - a straightforward issue report is the right way to flag it.
